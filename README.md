# QGDS Community

> [!WARNING]
> **This repository is not live, public or supported.**
> It is a proof of concept for a more integrated community management system for the Queensland Government Design System (QGDS). Content here may be incomplete, out of date or removed without notice. Do not rely on it for production work, and do not treat anything here as official QGDS guidance.
>
> For the official design system, use [designsystem.qld.gov.au](https://www.designsystem.qld.gov.au).

---

## About this repository

This repository explores how the QGDS community could share documentation, raise questions and discuss the design system in one place.

The aim is to test whether a single, integrated space can bring together the conversations that currently happen across separate channels. This includes questions about components, requests for new patterns, feedback on existing guidance and examples of QGDS in use.

## What's here

- **Documentation** — draft and working documentation for components, patterns and foundations. These drafts are not reviewed or endorsed.
- **Discussions** — a space to ask questions, share work and suggest changes. Use the Discussions tab to browse or start a thread.
- **Issues** — used to track proposals, bugs and feedback raised through the community.

## Contributing

Contributions are not open yet. If you have been invited to test this proof of concept, use Discussions to share feedback on how the community space works, as well as the content in it.

When contribution guidelines are ready, they will be added to this repository.
