The design system gives designers and developers a shared set of foundations,
components and patterns. Using it means teams spend less time rebuilding common
interface problems and more time on the parts of a service that are specific to
their users.

Everything published here is built on the [QGDS web components](https://github.com/qld-gov-au/qgds-web-components)
library and meets [WCAG 2.2](https://www.w3.org/TR/WCAG22/) Level AA.
