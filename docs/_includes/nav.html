{%- comment -%} ================================================================================ Whole-site vertical navigation — ================================================================================ One navigation for the entire site, built from the repository folder structure. Nothing is hand-maintained: drop a .md file into a section folder and it appears here. REQUIRES a build of @qld-gov-au/qgds-web-components that includes . That component is NOT in 0.3.4 (the newest npm release at the time of writing) — see README, "Loading the components". Against 0.3.4 the elements below do not upgrade and the nav renders empty. Structure it understands (these are SOURCE paths, so this is independent of whatever `permalink` style you use): components/index.md -> level 1 item components/button.md -> level 2, under "Components" components/form/index.md -> level 2, under "Components" components/form/text-input.md -> level 2, listed after "Form" qgds-navigation-item supports exactly two levels: a level-1 item sets `level = 2` on its children, and a level-2 item scrubs any children of its own. A third level is therefore flattened into level 2, emitted directly after its parent folder so reading order still groups it. Front matter each page can set: title: required — a page without a title is skipped nav_title: optional shorter label to show in the nav nav_order: optional integer, ascending (default 100 via _config.yml) nav_exclude: optional, true to hide the page from navigation `is-active` is all that is needed to mark the current page: in vertical mode the component opens the parent of an active child by itself. ================================================================================ {%- endcomment -%} {%- assign nav_pages = site.pages | where_exp: "p", "p.title" | where_exp: "p", "p.nav_exclude != true" | sort: "nav_order" -%} {%- for section in nav_pages -%} {%- assign sseg = section.path | split: "/" -%} {%- if sseg.size != 2 or sseg[1] != "index.md" -%}{%- continue -%}{%- endif -%} {%- assign section_slug = sseg[0] -%} {%- for item in nav_pages -%} {%- assign seg = item.path | split: "/" -%} {%- if seg[0] != section_slug -%}{%- continue -%}{%- endif -%} {%- assign depth = seg | size -%} {%- comment -%} A file directly in the section folder {%- endcomment -%} {%- assign is_leaf = false -%} {%- if depth == 2 and seg[1] != "index.md" -%}{%- assign is_leaf = true -%}{%- endif -%} {%- comment -%} The index.md of a sub-folder {%- endcomment -%} {%- assign is_folder = false -%} {%- if depth == 3 and seg[2] == "index.md" -%}{%- assign is_folder = true -%}{%- endif -%} {%- unless is_leaf or is_folder -%}{%- continue -%}{%- endunless -%} {%- comment -%} A sub-folder's pages, flattened to level 2 and emitted right after their folder so they still read as a group. {%- endcomment -%} {%- if is_folder -%} {%- assign folder_slug = seg[1] -%} {%- for child in nav_pages -%} {%- assign cseg = child.path | split: "/" -%} {%- if cseg.size != 3 -%}{%- continue -%}{%- endif -%} {%- if cseg[0] != section_slug -%}{%- continue -%}{%- endif -%} {%- if cseg[1] != folder_slug -%}{%- continue -%}{%- endif -%} {%- if cseg[2] == "index.md" -%}{%- continue -%}{%- endif -%} {%- endfor -%} {%- endif -%} {%- endfor -%} {%- endfor -%}
