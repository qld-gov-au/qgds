# QGDS site (Jekyll)

- `_includes/sidebar.md` — the sidebar, shown on every page
- `_includes/footer.md` — the footer, shown on every page
- `_layouts/default.html` — the page shell that loads both
- `index.md` — the home page

To add a page, create a `.md` file with a title at the top:

    ---
    title: Accordion
    ---

It picks up the sidebar and footer automatically.
