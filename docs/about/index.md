The design system is maintained by the Queensland Government design system team.
It exists so that teams across government stop solving the same interface
problems separately, and so that the services Queenslanders use behave
consistently.

## What is in scope

- Foundations: colour, typography, spacing, layout, iconography
- Components: individual interface elements
- Patterns: proven combinations of components
- Templates: whole-page structures

## What is out of scope

- Service design and journey mapping
- Content strategy and information architecture
- Agency-specific business rules

## Status

The web components library is **pre-release**. Expect breaking changes between
minor versions, pin an exact version, and read the release notes before
upgrading.
