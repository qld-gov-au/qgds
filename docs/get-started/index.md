The design system is made up of four layers. Each one builds on the one before
it, so start at the top and work down.

| Layer | What it gives you |
|---|---|
| Brand requirements | Which brand applies to your service and how to apply it |
| Core styles | Colour, type, spacing and layout foundations |
| Components | Individual interface elements, ready to use |
| Patterns and templates | Proven ways of combining components to solve a user task |

If you are designing, start with **Designing**. If you are building, start with
**Developing**.
