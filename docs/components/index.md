A component solves one interface problem. Compose components to build a page;
do not modify a component to fit a page.

Each component page follows the same structure:

- **Overview** — what it does and which variants exist
- **Usage guidance** — when to use it, and when not to
- **Design rationale** — why it works this way, and the research behind it
- **Accessibility** — the WCAG criteria it satisfies and what you still own
- **Implementation** — the markup, attributes and slots

Components are published as custom elements prefixed `qgds-`. Full API
documentation and interactive controls are in the
[Storybook](https://qld-gov-au.github.io/qgds-web-components/).
