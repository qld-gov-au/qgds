A component is a part. A pattern is a way of assembling parts to solve a problem
users keep running into — proving identity, paying a fee, finding a service near
them.

Patterns are added when the same combination has been built and tested more than
once. If you have solved a problem that is not documented here, propose it
through [Contribute]({{ '/about/contribute.html' | relative_url }}).
